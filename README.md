# MetaScalp Link

Статическая страница открывает инструменты из ссылки в двух существующих стаканах MetaScalp. Сначала подключите нужные биржи и откройте два разных несвязанных стакана на одной вкладке. Для Binance и Bybit можно выбрать режим «Только просмотр» (View Only) при добавлении подключения и выборе рынка: API-ключи для него не нужны.

Откройте ссылку, разрешите браузеру доступ к локальной сети при запросе, нажмите «Подключить» и выберите подключения и стаканы. После настройки следующие ссылки автоматически проверяют и открывают выбранные стаканы, если найден один сохранённый экземпляр MetaScalp. При нескольких экземплярах потребуется выбор. Настройка хранится в браузере и проверяется заново перед каждым изменением.

Пример:

```text
https://punkbasster.github.io/metascalp-link/#longExchangeId=4&longExchangeId=6&longMarketType=2&longMarketType=5&longTicker=BLURUSDT&longLabel=Bybit%2FBybitUta%20USDT%20Perpetual&shortExchangeId=2&shortMarketType=2&shortTicker=BLURUSDT&shortLabel=Binance%20USDT%20Futures
```

Для каждой стороны повторяемые `ExchangeId` и `MarketType` содержат допустимые числовые идентификаторы MetaScalp, `Ticker` — буквальные альтернативные имена из MetaScalp, а `Label` — название для показа. Страница не преобразует названия площадок и тикеры. Совпадение имени тикера без учёта регистра должно быть единственным; неоднозначность блокирует действие.

Страница обращается только к `127.0.0.1:17845–17855`, проверяет `/ping`, читает подключения, тикеры и состояние интерфейса, затем адресно меняет два стакана и ограниченное время ждёт подтверждения. Частичный результат показывается отдельно; автоматического повтора записи нет. Вкладка активируется только после подтверждения обоих стаканов. Связанные группы и настройки не меняются. Счета, балансы и ордера не запрашиваются. При тайм-ауте проверьте интерфейс перед повтором. Доступ к локальной сети зависит от браузера и его разрешений.

GitHub Pages публикует корень репозитория как статический сайт. Зависимостей, CDN, аналитики и service worker нет. Для проверки: `node --test *.test.mjs`. Контракт API: [MetaScalp API](https://github.com/MetaScalp/metascalp-sdk/blob/main/docs/MetaScalp-Api.md).

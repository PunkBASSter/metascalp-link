# MetaScalp Link

Статическая страница для открытия двух указанных в ссылке инструментов в существующих стаканах MetaScalp. В MetaScalp заранее создайте два разных стакана без связанных групп на одной вкладке и подключите нужные биржи. Откройте ссылку, разрешите браузеру доступ к локальной сети при запросе, нажмите «Подключить», выберите экземпляр, подключения и стаканы. При нескольких подходящих подключениях выбор обязателен. После настройки следующие ссылки автоматически проверяют и открывают выбранные стаканы, если найден один сохранённый экземпляр MetaScalp. При нескольких экземплярах потребуется выбор. Настройка и выбранные подключения сохраняются в браузере и каждый раз проверяются заново.

Пример: `https://punkbasster.github.io/metascalp-link/#longVenue=GATEIO-FUTURES&longTicker=POWR_USDT&shortVenue=BINANCE-FUTURES&shortTicker=POWRUSDT`. Указываются собственные тикеры бирж, а не обозначения TradingView. Поддерживаются BINANCE-SPOT/FUTURES, BYBIT-SPOT/LINEAR, OKX-SPOT/SWAP, BITGET-LINEAR, GATEIO-SPOT/FUTURES, KUCOIN-SPOT/LINEAR; фьючерсные ссылки предназначены для USDT-линейных бессрочных контрактов. Разные типы USDT-фьючерсов MetaScalp требуют явного выбора, если найдено несколько подключений. Совпадение тикера определяется точно или с удалением разделителей `-`, `_`, `/`; для OKX SWAP учитывается суффикс `-SWAP`, для KuCoin Linear — `USDTM` и пара BTC/XBT. Неоднозначность блокирует действие.

Страница обращается только к `127.0.0.1:17845–17855`, проверяет ответ `/ping`, читает список подключений, тикеры и состояние интерфейса, затем адресно меняет два стакана и ограниченное время ждёт подтверждения. Частичный результат показывается отдельно; автоматического повтора записи нет. Вкладка активируется только после подтверждения обоих стаканов на одной вкладке. Связанные группы и настройки не меняются. Счета, балансы и ордера не запрашиваются. MetaScalp API асинхронен: при тайм-ауте проверьте интерфейс перед повтором. Доступ к локальной сети и поддержка HTTPS → loopback зависят от браузера и его разрешений.

GitHub Pages: публикуйте корень репозитория как статический сайт. Зависимостей, CDN, аналитики и service worker нет. Для локальной проверки запустите статический HTTP-сервер в этом каталоге и `node --test *.test.mjs`. API: [MetaScalp API](https://github.com/MetaScalp/metascalp-sdk/blob/main/docs/MetaScalp-Api.md).
